## Lo que hago

- **IA aplicada:** integración de LLMs (Claude, OpenAI, Gemini y modelos locales con Ollama), RAG con embeddings y pgvector, agentes con tool calling, Model Context Protocol (MCP) y salidas estructuradas en JSON. Atención a costos, latencia, privacidad y manejo de fallos del modelo.
- **Automatización:** flujos con n8n que conectan modelos, bases de conocimiento y servicios externos.
- **Backend:** APIs REST y microservicios con Node.js/TypeScript (NestJS, Express), PHP (Drupal, Laravel), Java (Spring Boot) y Python (FastAPI). Integraciones REST, SOAP y Active Directory.
- **Frontend:** React, Next.js y Angular.
- **Datos:** PostgreSQL, MySQL, Redis y MongoDB.
- **Infraestructura:** servidores Linux con hardening, Docker, Coolify, Nginx, Cloudflare Tunnel y CI/CD con GitHub Actions, GitLab y Azure DevOps.
